## Test servers

`playwright.config.ts` starts two Node servers (reused if already running):

| URL | env | used by |
|---|---|---|
| http://localhost:8080 | `NODE_ENV=test PUBLIC_ORIGIN=http://localhost:8080 ROOM_CREATE_PER_MIN=10000 MAX_ROOMS=5000` | everything |
| http://localhost:8081 | same + `TEST_TIME_SCALE=60` | idle / hard expiry specs only |

The 60x clock lives on its own server so that the 30 s (scaled) idle timeout cannot make the
ordinary multi-user specs flaky. `ROOM_CREATE_PER_MIN` is raised because specs create many rooms
from one address (max accepted by `readLimits` is 10000).
