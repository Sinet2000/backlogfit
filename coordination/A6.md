## Decisions

- **gitleaks** runs as the official release binary verified by SHA-256 (v8.30.1), not
  `gitleaks/gitleaks-action` (proprietary EULA, contacts a license server). Keeps CI free of
  non-OSS code and third-party calls.
- **SBOMs** (workspace and image) are generated with Trivy (CycloneDX) via the same pinned
  `trivy-action` used for the image scan, so the release needs no extra SBOM tool. BuildKit also
  attaches its own SBOM/provenance; `actions/attest-build-provenance` + `actions/attest-sbom`
  add GitHub attestations; cosign signs keyless.
- **GitHub release** is created with the `gh` CLI (preinstalled on runners) instead of a
  third-party release action.
- Image is scanned (amd64, loaded locally) **before** anything is pushed; push is
  amd64 + arm64.
- DCO check: pure shell, requires a `Signed-off-by` trailer equal to the commit author for
  every non-merge commit in a PR.
- Code of Conduct reporting: GitHub "Report content → Report to repository admins" (the
  maintainer must enable *Settings → Moderation → Reported content*) or GitHub's abuse form.
  No email anywhere.
- Harden-runner is used in `audit` mode on all jobs except DCO.
