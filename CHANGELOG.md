## [0.1.0] - Unreleased

First public release.

### Added

- Rooms with Fibonacci, modified Fibonacci, powers of two, T-shirt and custom card decks.
- Facilitator controls: task list, reveal, re-vote with history, final estimate, timer,
  lobby, passcode, lock, kick, co-facilitators, spectators, anonymous reveal.
- Statistics (distribution, median, mode, average, consensus) and CSV/JSON/Markdown exports.
- Privacy model: secrets in the URL fragment, hashes only on the server, no vote values
  before reveal, automatic deletion on expiry.
- Cloudflare Worker backend and a self-hostable Node server container image.
- Content pages, FAQ and Manager Guide.
